The AI on Life Island, and its guardrails

Life Island is live and open source (MIT): a living 3D world (Three.js + TypeScript) where 24 villagers talk through Claude Haiku 4.5.

  • Claude Haiku 4.5 behind a Firebase callable. The API key lives in Secret Manager, and calls without a valid App Check token are rejected.
  • Per-IP burst limits. Anonymous IDs are free to mint, so the limits are keyed by IP address.
  • A hard monthly token cap. When it is reached, the villagers fall back to scripted lines.
  • Moderation on input and output, with visitor text fenced as data (prompt-injection fencing).
  • A planner that can't publish free text. A scheduled planner picks the day's events by index from pre-written pools. Ids are validated on the server and again on the client, so no planner text reaches a public surface.

Also in the repo: a nightly analyst agent (Claude Sonnet) that emails a usage digest and files GitHub issues; ElevenLabs speech through a capped function, with browser speech as the fallback; and a Vitest suite, typecheck, lint and Prettier in CI (GitHub Actions). Read the functions code.
